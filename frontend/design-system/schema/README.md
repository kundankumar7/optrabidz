# Design token schemas

These schemas are maintained by the OptraBidz project. They are not official Design Tokens Community Group schemas.

The supported token profile follows the normative [Design Tokens Format Module 2025.10](https://www.designtokens.org/tr/2025.10/format/). The project schema is registered under `urn:optrabidz:design-tokens:schema:2025.10`; conformance behavior that JSON Schema cannot express is enforced by executable fixtures and semantic validation.

Schema changes require a revision increment, a new checksum in the token manifest, and passing conformance tests. A newer DTCG report is adopted only through an explicit migration.
